# TrackPulse – Smart Railway Safety Prototype

## Overview
TrackPulse is an Arduino-based railway safety prototype designed to detect railway track cracks and obstacles.

## Features
- Crack detection
- Obstacle detection
- Buzzer alert
- Relay activation
- Servo gate control

## Components Used
- Arduino UNO
- HC-SR04 Ultrasonic Sensor
- Servo Motor
- Relay Module
- Buzzer
- Breadboard
- Jumper Wires

## Working Principle
The system monitors railway track continuity. If continuity breaks(blue and green jumper wires are used), the system identifies it as a crack and activates alerts.

The ultrasonic sensor detects nearby obstacles and triggers safety actions.
